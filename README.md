# SC 빌드오더 연습기

스타크래프트: 브루드워의 빌드오더 타이밍을 연습하기 위한 개인용 웹 시뮬레이터(PWA)입니다.
실제 컨트롤/전투는 다루지 않고, **경제(미네랄/가스/일꾼)와 인구수(서플라이)를 실제 게임과 비슷하게 시뮬레이션**하면서
정확한 타이밍에 건물/유닛 버튼을 누르는 연습을 할 수 있습니다.

## 플레이 방법

1. 종족(테란/저그/프로토스)과 연습할 빌드오더를 선택합니다.
2. 시간이 흐르며 미네랄/가스가 자동으로 쌓입니다 (일꾼 수에 비례).
3. 화면 우측(모바일에서는 상단) 커맨드 카드에서 건물/유닛 버튼을 눌러 빌드오더를 따라갑니다.
4. 왼쪽 빌드오더 체크리스트에서 각 단계가 목표 인구수/시간 대비 얼마나 정확했는지 확인합니다.
5. 배속(일시정지/1x/2x/4x/8x)으로 연습 속도를 조절할 수 있습니다.

## 화면 구성 (반응형)

- **모바일**: 커맨드 카드 → 체크리스트 → 현황 순으로 세로 스택, 큰 터치 버튼.
- **태블릿**: 커맨드 카드가 상단, 체크리스트/현황이 하단 2열.
- **와이드 데스크톱(1100px 이상)**: 실제 스타크래프트 하단 UI와 유사하게 좌(미니맵 자리=체크리스트) · 중(포트레이트 자리=현황) · 우(커맨드 카드) 3분할 콘솔 레이아웃.

## 수치에 대한 안내

건물/유닛의 미네랄/가스/시간/인구수 값은 실제 브루드워 수치에 최대한 가깝게 맞췄지만, 일꾼 채집 속도(초당
약 0.7 자원/일꾼)는 커뮤니티에서 통용되는 근사치입니다. 프레임 단위로 완벽히 동일하지는 않으니,
"몇 인구에 무엇을 짓는가" 같은 빌드오더 순서·타이밍 감각을 익히는 연습용으로 사용해주세요.

## 포함된 빌드오더

- **테란**: 1배럭 더블, 8배럭 러시, 5배럭 마린 올인, 1-1-1 시즈 확장, 2팩토리 벌처 하라스, 레이스 러시,
  배틀크루저 테크 러시, 벙커링, 터렛 확장(터틀 FE), 1배럭 2팩토리 골리앗, 발키리 방어 빌드, 노 배럭 더블 — 총 12종
- **저그**: 9드론 오버로드 표준, 6풀 저글링 러시, 뮤탈리스크 테크 러시
- **프로토스**: 1게이트 사이버네틱스 코어 표준, 포지 캐논 방어, 다크템플러 러시

`data.js`의 `BUILD_ORDERS`에 항목을 추가하면 빌드오더를 쉽게 늘릴 수 있습니다.

## 기술 스택

번들러 없는 순수 HTML/CSS/JS + PWA (manifest + service worker). GitHub Pages에서 정적 파일로 바로 서빙됩니다.
