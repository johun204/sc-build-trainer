# SC 빌드오더 연습기

스타크래프트: 브루드워의 빌드오더 타이밍을 연습하기 위한 개인용 웹 시뮬레이터(PWA)입니다.
실제 컨트롤/전투는 다루지 않고, **경제(미네랄/가스/일꾼)와 인구수(서플라이)를 실제 게임과 비슷하게 시뮬레이션**하면서
정확한 타이밍에 건물/유닛 버튼을 누르는 연습을 할 수 있습니다.

## 플레이 방법

1. 시작 화면에서 종족(테란/저그/프로토스)과 연습할 빌드오더를 순서대로 선택하고 "시작"을 누릅니다.
2. 화면은 스크롤 없이 한 화면 안에서 완결됩니다: 상단 자원 표시줄 → 항상 보이는 "베이스 뷰"(일꾼이
   실제로 미네랄/가스를 캐러 왕복) → [체크리스트/명령] 탭.
3. 실제 스타크래프트처럼 대상을 먼저 선택한 뒤 그 대상이 할 수 있는 행동만 아래에 나타납니다.
   "명령" 탭에서 일꾼을 선택하면 건물 건설 목록과 정찰 보내기가 나타나고, 배럭스처럼 생산 건물을
   선택하면 그 건물이 뽑을 수 있는 유닛만 나타납니다(베이스 뷰의 건물 아이콘을 직접 클릭해도 동일하게
   선택됩니다).
4. "체크리스트" 탭에서 각 단계가 목표 인구수/시간 대비 얼마나 정확했는지 확인하고, 다음 조건이
   충족되는 순간 화면 하단에 다음 할 일이 자동으로 뜹니다.
5. 배속(일시정지/1x/2x/4x/8x)으로 연습 속도를 조절하고, 상단 "메뉴" 버튼으로 언제든 시작 화면으로
   돌아가 종족/빌드오더를 다시 고를 수 있습니다.

## 화면 구성

페이지 자체는 절대 스크롤되지 않습니다(모바일 포함, 모든 화면 크기에서 화면 높이 고정). 목록이 길 때는
그 목록 내부에서만 스크롤됩니다.

- 좁은 화면(모바일/태블릿): 상단바 → 베이스 뷰 → [체크리스트|명령] 탭으로 전환하며 사용.
- 넓은 화면(800px 이상): 탭 없이 체크리스트와 명령 패널을 좌우로 나란히 배치해 둘 다 항상 보이는
  실제 스타크래프트 하단 UI에 가까운 레이아웃.

## 수치에 대한 안내

건물/유닛 비용·생산시간은 [Liquipedia StarCraft: Brood War Wiki](https://liquipedia.net/starcraft/)의
Mining, Terran/Zerg/Protoss Building·Unit Statistics 문서에서 조사한 실제 수치(Fastest 기준 초 단위)를
사용했습니다.

채집 메커니즘도 실측 자료를 반영했습니다:
- **미네랄**: 일꾼은 패치 1개당 1기(1.0x 포화)까지는 풀 속도(SCV 분당 65 / 드론 67.1 / 프로브 68.1)로
  채집하고, 그 이상(1.0x~3.0x, 패치당 최대 3기)부터는 왕복 대기시간 때문에 훨씬 느린 추가 속도(약 0.6배)로만
  늘어나며, 3.0x를 넘는 일꾼은 채집량에 기여하지 못합니다. 한 커맨드 센터/해처리/넥서스당 미네랄 패치 8개로
  가정합니다.
- **가스**: 정제 건물 1개당 일꾼 3기가 풀 포화(분당 약 103)이며, 4기째부터는 대기만 하고 추가 채집량이
  없습니다(가스 일꾼 UI에 포화/유휴 인원이 표시됩니다).
- 일꾼을 가스로 돌리면 그만큼 미네랄 채집 인원이 줄어 미네랄 채집 속도도 함께 감소합니다.

프레임 단위로 완벽히 동일하지는 않지만, "몇 인구·몇 자원에 무엇을 짓는가" 같은 빌드오더 순서·타이밍 감각을
익히는 연습용으로는 충분히 정확합니다.

## 채집 방식 (일꾼 개체별 시뮬레이션)

미네랄/가스는 평균 rate 공식이 아니라 일꾼 한 명 한 명을 실제 상태기계로 시뮬레이션합니다. 각 일꾼은
다음 상태를 순서대로 거칩니다:

1. 이동(본진→자원): 종족별 실측 이동 시간(SCV/드론/프로브마다 다름).
2. 대기: 같은 미네랄 패치를 캐는 다른 일꾼이 있어 순서를 기다리는 시간(포화 공식 기반, 패치가 붐빌수록
   길어짐). 가스는 건물당 3기까지는 대기 없이 바로 채집하고, 4기째부터는 자리가 날 때까지 무기한 대기.
3. 채집: 실측 채집 동작 시간(미네랄 80프레임 / 가스 37프레임) 동안 그 자리에 머뭅니다.
4. 이동(자원→본진): 도착하는 순간 실제 자원 수치가 +8 증가합니다(캐리 중인 일꾼은 베이스 뷰에서 금색
   테두리로 표시).

일꾼은 한번 배정된 미네랄 패치를 계속 사용합니다(스티키 배정). 새로 뽑힌 일꾼이나 가스에서 복귀한
일꾼은 그 순간 가장 비어있는 패치로 자동 배정됩니다.

## 베이스 뷰 (그래픽, 항상 표시)

상단바 바로 아래 "베이스 뷰"가 항상 화면에 고정되어 있습니다(스크롤해도 사라지지 않고, 일정 이상
스크롤하면 작게 축소됩니다). 본진 건물, 미네랄 패치 8개, 가스 건물이 표시되고 일꾼들이 위에서 설명한
상태기계 그대로(이동 → 대기 → 채집 → 이동) 애니메이션됩니다. 건설된 다른 건물들은 아래 갤러리에
종족별 스타일 아이콘(테란=강철 사각형, 저그=유기체 블롭, 프로토스=크리스탈 육각형)으로 표시되며,
건설 중인 건물은 남은 시간이 오버레이되고 우측 상단 × 버튼으로 바로 취소할 수 있습니다. 실제 게임
스프라이트 대신 저작권 문제 없는 자체 스타일 아이콘을 사용합니다.

## 건설 시 일꾼 처리 (종족별 차이)

- 테란: SCV 1기가 건물이 완성될 때까지 채집을 완전히 멈추고 그 자리를 지킵니다(베이스 뷰에서 사라지고
  "건설 중" 배지로 표시). 완성되면 자동으로 가장 비어있는 패치로 복귀합니다.
- 프로토스: 프로브가 워프를 시작한 직후(약 1.5초) 바로 채집으로 복귀하고, 건물 자체는 독립적인
  타이머로 계속 지어집니다.
- 저그: 드론이 건물로 변태해 완전히 사라집니다(총 일꾼 수가 1 감소). 단, 레어/하이브는 기존
  해처리/레어 건물 자체가 변태하는 것이라 드론을 전혀 소모하지 않습니다.
- 건설 취소 시 자원 환불과 함께 묶여있던 일꾼(또는 소모된 드론)도 그대로 복구됩니다.

## 정찰

"명령" 탭에서 일꾼을 선택하면 나타나는 "일꾼 정찰 보내기" 버튼으로 일꾼 1기를 정찰 보낼 수 있습니다.
정찰 보낸 일꾼은 총 일꾼 수에는 포함되지만 채집 경제에서는 완전히 빠지며(베이스 뷰에 "정찰 중" 배지로
표시), 같은 자리에 나타나는 "정찰 복귀" 버튼을 누르면 다시 채집에 투입됩니다.

## 생산 UI

- "명령" 탭의 선택 줄(또는 베이스 뷰 아이콘)에서 유닛을 생산할 수 있는 건물(배럭스, 팩토리, 게이트웨이
  등)을 선택하면 그 건물에서만 뽑을 수 있는 유닛 버튼과, 건물별 개별 생산 대기열(진행률 바 + 대기 인원)이
  나타납니다. 예: 배럭스가 2개면 마린 2기를 동시에 생산하고, 3번째는 먼저 찬 배럭스의 대기열에
  들어갑니다(건물당 최대 5개 대기, 실제 게임과 동일).
- 저그는 라바가 공용 자원이라 선택 줄에서 라바를 고르면 항상 그 패널에서 유닛을 뽑습니다.
- 건물 건설은 일꾼을 선택했을 때만 나타납니다(항상 떠 있지 않음) - 실제 스타크래프트에서 일꾼을
  선택해야 건물을 지을 수 있는 것과 동일한 조작 방식입니다.

## 포함된 빌드오더

- **테란**: 1배럭 더블, 8배럭 러시, 5배럭 마린 올인, 1-1-1 시즈 확장, 2팩토리 벌처 하라스, 레이스 러시,
  배틀크루저 테크 러시, 벙커링, 터렛 확장(터틀 FE), 1배럭 2팩토리 골리앗, 발키리 방어 빌드, 노 배럭 더블 — 총 12종
- **저그**: 9드론 오버로드 표준, 6풀 저글링 러시, 뮤탈리스크 테크 러시
- **프로토스**: 1게이트 사이버네틱스 코어 표준, 포지 캐논 방어, 다크템플러 러시

`data.js`의 `BUILD_ORDERS`에 항목을 추가하면 빌드오더를 쉽게 늘릴 수 있습니다.

## 기술 스택

번들러 없는 순수 HTML/CSS/JS + PWA (manifest + service worker). GitHub Pages에서 정적 파일로 바로 서빙됩니다.
